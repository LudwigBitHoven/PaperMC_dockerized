## Как с этим взаимодействовать

Сервер запускается на основе образа `marctv/minecraft-papermc-server:1.21.4-232`

Команда `docker compose up` запускает сервер на порту `27000` с плагинами Chunky и WorldEdit, изменить порт можно в файле `docker-compose.yaml`, там же можно настроить потребление сервером ресурсов ОЗУ

Оптимизированный конфиг PaperMC составлен по этой [инструкции](https://www.youtube.com/watch?v=INODEOVmCg0)

Консольные команды minecraft можно вводить так: получаем ID-контейнера из `docker container ls`, цепляемся к контейнеру по его ID как `docker attach <container-id>`, пишем нужные команды без слэша

## Бекапирование

WorldEdit позволяет использовать команду `snap`, чтобы локализованно накатывать бекапы/снэпшоты мира. 

Чтобы настроить бекапирование надо ввести `crontab -e` и записать конфигурацию вида:

```bash
0 6 * * 1,3,5,7 cd /home/<username>/PaperMC_dockerized && ./backup-world.sh > /home/<username>/backup-world.log 2>&1
```

Эта конфигурация запускает скрипт в 6:00 каждый нечетный день недели. Своё расписание для крон бекапа можно составить [тут](https://crontab.guru/)

По-умолчанию скрипт `backup-world.sh` удаляет файлы миров старше 14 дней
